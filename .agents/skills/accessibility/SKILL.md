# Accessibility — доступность интерфейса (WCAG AA)

Проектный скилл для обеспечения базовой и практической доступности платформы хакатонов: комфортное чтение, полноценная работа с клавиатуры и скринридеров, удобные тач-цели и бережная работа с анимациями.

## Когда применять

- При создании и обновлении любых интерактивных элементов: навигации, карточек-ссылок, форм, модальных окон, кнопок, бейджей и уведомлений.
- При изменении цветовых токенов в `src/app/globals.css` и вариантов компонентов в `src/components/ui/*`.
- При аудите доступности страниц перед релизом или редизайном.

## Чек-лист проверки

### 1. Контраст не ниже WCAG AA
- [ ] Обычный текст (до 18px) имеет контраст к фону не ниже **4.5:1**, крупный текст (от 18px bold / 24px regular) и границы UI-контролов — не ниже **3:1**.
- [ ] Вторичный текст (`text-muted-foreground`), текст в `readOnly`/`disabled` полях и цветные бейджи статусов (`--status-*`, `--format-*` на полупрозрачном фоне `/10`) остаются читаемыми по WCAG AA.
- [ ] Смысл статуса, ошибки или выбранного шага не передаётся только цветом: используются также текст и/или иконка.

### 2. Видимый фокус, клавиатура и порядок табуляции
- [ ] Каждый интерактивный элемент (`a`, `button`, `input`, `textarea`, `select`, радиокнопки, элементы диалогов) доступен с клавиатуры (`Tab` / `Shift+Tab`) в логическом порядке, совпадающем с визуальным.
- [ ] При фокусе с клавиатуры (`:focus-visible`) виден чёткий контрастный контур (`outline-2 outline-offset-2 outline-ring` или `ring-3 ring-ring/50`).
- [ ] Не допускается `outline-none` без равноценной видимой замены контура.
- [ ] Мобильное меню и модальные окна поддерживают закрытие по `Escape` и возврат фокуса; у мобильного меню корректно связаны `aria-expanded` и `aria-controls`.
- [ ] Декоративные иконки (`lucide-react`) рядом с текстом помечены `aria-hidden="true"`, а кнопки только с иконкой имеют понятный `aria-label`.

### 3. Связь `label` и полей, `aria-describedby` для ошибок
- [ ] У каждого поля ввода есть видимый `<Label htmlFor="...">`, связанный с `id` контрола; для групп радиокнопок используются `<fieldset>` и `<legend>`.
- [ ] При ошибке валидации на поле выставлен `aria-invalid={true}`, а `aria-describedby` ссылается на `id` сообщения об ошибке (и при наличии постоянной подсказки сохраняет связь с подсказкой тоже, например `"field-hint field-error"`).
- [ ] Общие ошибки формы и диалогов используют `role="alert"`, сообщения об успехе и копировании — `role="status"` или `aria-live="polite"`.
- [ ] На навигации заданы `aria-label` и `aria-current="page"` (для шагов мастера — `aria-current="step"`).

### 4. Тач-цели ~44px
- [ ] Все кликабельные кнопки, ссылки навигации, поля ввода, `select` и элементы диалогов имеют минимальную высоту/ширину **44px** (`min-h-11` / `min-w-11`), особенно на мобильных устройствах.
- [ ] Между соседними кнопками и ссылками есть достаточный зазор (`gap-2` / `gap-2.5` и более), исключающий случайные нажатия.
- [ ] Кнопки подтверждения и отмены внутри `AlertDialogFooter` также соответствуют размеру тач-цели ~44px.

### 5. `prefers-reduced-motion`
- [ ] В `src/app/globals.css` или на анимируемых компонентах предусмотрена поддержка `@media (prefers-reduced-motion: reduce)`: отключение или сведение к минимуму анимаций `tw-animate-css`, переходов и смещений (`active:translate-y-px`).
- [ ] Ни один важный сценарий (показ ошибки, открытие диалога, переход шага) не зависит от завершения CSS-анимации.

## Критерии приёмки

- Страница полностью проходима клавишами `Tab`, `Shift+Tab`, `Enter`, `Space`, `Escape` без «ловушек» фокуса и невидимых фокусов.
- У всех полей форм проверены пары `Label`/`id`, `aria-invalid`, `aria-describedby` и `role="alert"`/`role="status"`.
- Все основные интерактивные контролы (включая кнопки в модальных окнах) имеют размер тач-цели не ниже 44px.
- В глобальных стилях и анимациях учтён `prefers-reduced-motion`.

## Явные запреты

- Запрещено сбрасывать видимый фокус через `focus-visible:outline-none` без явного `focus-visible:ring-*` или `focus-visible:outline-*`.
- Запрещено использовать `placeholder` вместо `<Label>` или оставлять кнопки только с иконкой без `aria-label`.
- Запрещено оставлять на интерактивных кнопках, ссылках-кнопках и кнопках диалогов высоту меньше 44px (`h-6`, `h-7`, `h-8`) на мобильных экранах.
- Запрещено игнорировать `prefers-reduced-motion` при использовании `tw-animate-css` и CSS-переходов.

## Примеры из проекта

### Хорошие решения
- `src/app/globals.css` (строки 108–113): задано базовое правило видимого фокуса `outline-2 outline-offset-2 outline-ring` для `a`, `button`, `input`, `[tabindex]`.
- `src/components/layout/header-nav.tsx` (строки 20–30, 114–123): семантический `<nav aria-label="Основная навигация">`, `aria-current="page"`, кнопка мобильного меню с `aria-expanded`, `aria-controls="mobile-nav"`, `aria-label` и размером `min-h-11 min-w-11` (44×44px).
- `src/components/create-hackathon-wizard.tsx` (строки 400–403, 452–488, 636–640): корректные `aria-current="step"`, связка `<Label htmlFor>`, `aria-invalid`, `aria-describedby`, `<fieldset>` + `<legend>` для выбора формата.
- `src/components/submission-form.tsx` (строки 348–365): для успеха используется `role="status"`, для ошибки — `role="alert"`, декоративные иконки помечены `aria-hidden="true"`.

### Проблемные решения (что нужно улучшать)
- `src/app/globals.css` (строки 98–114): отсутствует блок `@media (prefers-reduced-motion: reduce)` при подключённом `@import "tw-animate-css"`, а в списке `:focus-visible` (строки 108–111) пропущены `textarea` и `select`.
- `src/components/hackathon-manage-item.tsx` (строка 121): ссылка на заголовке хакатона использует `focus-visible:outline-none`, оставляя только подчёркивание вместо контрастного контура `outline-ring`.
- `src/components/hackathon-manage-item.tsx` (строки 243–251), `src/components/submission-form.tsx` (строки 588–598), `src/components/team-panel.tsx` (строки 830–873): кнопки `AlertDialogCancel` и `AlertDialogAction` не задают `min-h-11` и рендерятся высотой `h-8` (32px) из `button.tsx` — ниже тач-цели 44px.
- `src/components/hackathon-card.tsx` (строки 80, 90, 95, 106): декоративные иконки `Calendar`, `MapPin`, `Users`, `Trophy` не имеют `aria-hidden="true"`.
- `src/components/create-hackathon-wizard.tsx` (строки 421–426, 675–679): серверный `<Alert variant="destructive">` не имеет явного `role="alert"`, а ошибка выбора формата (`fieldErrors.format`) не связана с радиогруппой через `aria-describedby`.
- `src/components/layout/header-nav.tsx` (строки 126–142): открытое мобильное меню не закрывается по нажатию клавиши `Escape`.
- `src/components/team-panel.tsx` (строки 697–701): статус «Скопировано» на кнопке не объявляется скринридеру через `aria-live="polite"`.
