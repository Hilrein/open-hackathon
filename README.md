# Платформа хакатонов

Веб-платформа для организации, поиска и проведения хакатонов. На текущем этапе реализован базовый UI-каркас на русском языке без бизнес-логики и базы данных.

## Команды запуска

```bash
npm install
npm run dev
npm run build
npm run lint
```

## Структура основных папок

- `src/app/` — страницы приложения (App Router), корневой layout и глобальные стили.
- `src/components/layout/` — общий каркас приложения (`AppShell`).
- `src/components/ui/` — базовые UI-компоненты (`shadcn/ui`).
- `src/lib/` — вспомогательные утилиты.
- `docs/` — документация продукта, правила UX и правила работы для ИИ-агента.
