# API редактирования хакатона

## Эндпоинт

`PUT /api/hackathons/[slug]`

Обновляет существующий хакатон, созданный текущим авторизованным пользователем.

## Правила

- **Авторизация:** обязательна. При отсутствии сессии возвращается `401`.
- **Владение:** редактировать можно только собственный хакатон (`organizerId === session.user.id`). Для чужих или seed-хакатонов возвращается `403`.
- **Неизменяемые поля:** `slug`, `participantsCount`, `organizerId` и `createdAt` не меняются даже при передаче в теле запроса.
- **Вычисляемый статус:** `status` (`upcoming`, `active`, `finished`) пересчитывается на сервере по новым `startDate` и `endDate`.
- **Даты:** `startDate` может быть в прошлом (для уже идущих или завершённых хакатонов), при этом `endDate` обязательно должна быть позже `startDate`.
- **Очистка необязательных полей:** передача `null` (или пустой строки) для `maxParticipants` и `prizePool` очищает эти поля в базе; передача пустого массива `[]` для `tags` очищает теги; пустое значение `organizerName` подменяется именем или email текущего пользователя.

## Ответы

### Успех (`200 OK`)

```json
{
  "slug": "ai-hackathon-2026"
}
```

### Ошибки

- `401 Unauthorized` — пользователь не авторизован:

```json
{
  "error": "Войдите, чтобы редактировать хакатон."
}
```

- `403 Forbidden` — хакатон принадлежит другому пользователю (или seed-запись):

```json
{
  "error": "Вы можете редактировать только свои хакатоны."
}
```

- `404 Not Found` — хакатон с таким `slug` не найден:

```json
{
  "error": "Хакатон не найден."
}
```

- `400 Bad Request` — ошибка валидации полей:

```json
{
  "error": "Проверьте поля формы.",
  "fieldErrors": {
    "title": ["Название должно быть от 5 до 120 символов."]
  }
}
```
