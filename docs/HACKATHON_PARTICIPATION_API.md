# API участия в хакатоне

> Примечание: UI кнопки «Участвовать» будет подключён к этому API в следующем таске.

## Эндпоинты

- `POST /api/hackathons/[slug]/participate` — присоединиться к хакатону.
- `DELETE /api/hackathons/[slug]/participate` — отменить своё участие в хакатоне.

## Правила

- **Авторизация:** обязательна для обоих методов (`401`, если пользователь не вошёл).
- **Организатор:** владелец хакатона не может участвовать в собственном хакатоне (`403`).
- **Завершённые хакатоны:** присоединиться к хакатону с прошедшей `endDate` нельзя (`400`).
- **Дубликат:** один пользователь не может записаться на один и тот же хакатон дважды (`409`).
- **Лимит мест:** если указан `maxParticipants` и мест больше нет, запись отклоняется (`409`).

## Примеры ответов

### Успешное участие (`200 OK`)

```json
{
  "participating": true,
  "participantsCount": 125
}
```

### Успешная отмена (`200 OK`)

```json
{
  "participating": false,
  "participantsCount": 124
}
```

### Ошибки

- `401 Unauthorized` — нет сессии:

```json
{
  "error": "Войдите, чтобы участвовать в хакатоне."
}
```

- `403 Forbidden` — попытка организатора участвовать в своём хакатоне:

```json
{
  "error": "Организатор не может участвовать в своём хакатоне."
}
```

- `404 Not Found` — хакатон не найден или пользователь не участвует (при `DELETE`):

```json
{
  "error": "Хакатон не найден."
}
```

- `400 Bad Request` — хакатон уже завершён:

```json
{
  "error": "Хакатон уже завершён."
}
```

- `409 Conflict` — повторная запись или закончились места:

```json
{
  "error": "Свободных мест больше нет."
}
```
