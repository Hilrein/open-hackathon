# API оценивания работ

> Примечание: UI оценивания будет подключён в следующем таске.

## Эндпоинт

- `PUT /api/hackathons/[slug]/submissions/[submissionId]/review` — поставить или обновить оценку работе.
- `DELETE /api/hackathons/[slug]/submissions/[submissionId]/review` — снять оценку с работы.

## Правила

- **Авторизация и владение:** оценивать и снимать оценку может только владелец хакатона (`401` без сессии, `403` для других пользователей).
- **Статус хакатона:** постановка оценки (`PUT`) доступна только после завершения хакатона (`finished`, `400` если ещё не завершён). Снятие оценки (`DELETE`) доступно владельцу независимо от статуса.
- **Оценка и комментарий:** `score` — целое число от `1` до `10` (проверяется на сервере и ограничением `CHECK` в БД); `feedback` — необязательная строка до 2000 символов (пустая строка сохраняется как `null`).
- **Уникальность:** у одной работы может быть только одна оценка; повторный `PUT` обновляет существующую запись.
- **DTO работ:** поле `review` (`{ id, submissionId, score, feedback, createdAt, updatedAt }` или `null`) возвращается в ответах `GET /api/hackathons/[slug]/submission` и `GET /api/hackathons/[slug]/submissions`.

## Примеры ответов

### Успешная оценка (`200 OK`)

```json
{
  "review": {
    "id": "...",
    "submissionId": "...",
    "score": 9,
    "feedback": "Отличная реализация!",
    "createdAt": "2026-11-18T18:00:00.000Z",
    "updatedAt": "2026-11-18T18:05:00.000Z"
  }
}
```

### Успешное снятие оценки (`200 OK`)

```json
{
  "ok": true
}
```

### Ошибки

- `401 Unauthorized`: `{ "error": "Войдите, чтобы оценить работу." }`
- `403 Forbidden`: `{ "error": "Вы можете оценивать работы только своих хакатонов." }`
- `404 Not Found`: `{ "error": "Хакатон не найден." }` / `{ "error": "Работа не найдена." }` / `{ "error": "Оценка не найдена." }`
- `400 Bad Request`: `{ "error": "Оценивание доступно после завершения хакатона." }` или `{ "error": "Проверьте поля формы.", "fieldErrors": { "score": ["Оценка должна быть целым числом от 1 до 10."] } }`
