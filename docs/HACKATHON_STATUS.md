# Вычисление статуса хакатона

## Зачем это нужно

В таблице `hackathons` хранится поле `status` (`upcoming`, `active`, `finished`). Однако со временем оно может устаревать: например, хакатон был создан как `upcoming`, затем его даты начались или завершились, а запись в базе не обновлялась.

Чтобы интерфейс всегда показывал актуальное состояние без фоновых задач и cron-джоб, для UI статус всегда вычисляется по датам через `getHackathonEffectiveStatus` в [hackathon-status.ts](file:///Users/hilrein/Desktop/Projects/open-hackathon/src/lib/hackathon-status.ts).

## Правила

Для заданных `startDate`, `endDate` и текущего времени `now`:

- если `endDate <= now` → `finished` («Завершён»);
- иначе если `startDate <= now` → `active` («Идёт»);
- иначе → `upcoming` («Скоро»).

## Источник истины

Поле `status` в базе остаётся для совместимости и заполняется при создании/обновлении тем же helper-ом, но UI (каталог, главная страница, карточки и страница деталей) не считает сохранённое значение в базе источником истины и всегда вычисляет статус в маппере `mapHackathonRowToHackathon`.
