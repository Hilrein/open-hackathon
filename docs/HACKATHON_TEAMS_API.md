# API команд хакатона

> Примечание: UI для команд будет подключён в следующем таске. Сдача работ на этом этапе остаётся индивидуальной и не изменяется.

## Эндпоинты

- `GET /api/hackathons/[slug]/teams` — список команд хакатона (для участников и организатора).
- `POST /api/hackathons/[slug]/teams` — создать команду (создатель становится капитаном).
- `GET /api/hackathons/[slug]/teams/my` — получить свою команду в хакатоне (`team` или `null`).
- `DELETE /api/hackathons/[slug]/teams/my` — покинуть свою команду (для обычного участника).
- `POST /api/hackathons/[slug]/teams/join` — присоединиться к команде по коду приглашения (`inviteCode`).
- `DELETE /api/hackathons/[slug]/teams/[teamId]` — распустить команду (только капитан; участники удаляются каскадно).

## Правила

- **Доступ:** команды доступны участникам хакатона и его организатору (`401` без сессии, `403` посторонним).
- **Статус хакатона:** создавать, входить, выходить и распускать команды можно до завершения хакатона (`upcoming` и `active`); после `finished` изменения возвращают `400`, а просмотр (`GET`) остаётся доступен.
- **Одна команда на участника:** один пользователь может состоять только в одной команде в рамках одного хакатона (`409`).
- **Уникальность названия:** название команды (3–50 символов) уникально в рамках хакатона без учёта регистра (`409`).
- **Код приглашения:** 6 символов (`A–Z`, `0–9`), глобально уникален.
- **Капитан:** капитан не может выйти через `DELETE /teams/my` (`400`) — он может только распустить команду через `DELETE /teams/[teamId]`. Поле `viewerIsCaptain` в `TeamDTO` показывает, является ли текущий пользователь капитаном команды.

## Примеры ответов

### Успешное создание (`201 Created`) / вход (`200 OK`)

```json
{
  "team": {
    "id": "...",
    "hackathonSlug": "ai-assistants-2026",
    "name": "Alpha Team",
    "inviteCode": "AB12CD",
    "captainName": "Иван",
    "viewerIsCaptain": true,
    "memberCount": 1,
    "members": [
      {
        "id": "...",
        "name": "Иван",
        "isCaptain": true,
        "joinedAt": "2026-11-19T00:00:00.000Z"
      }
    ],
    "createdAt": "2026-11-19T00:00:00.000Z",
    "updatedAt": "2026-11-19T00:00:00.000Z"
  }
}
```

### Ошибки

- `401 Unauthorized`: `{ "error": "Войдите, чтобы создать команду." }`
- `403 Forbidden`: `{ "error": "Сначала присоединитесь к хакатону." }` / `{ "error": "Только капитан может распустить команду." }`
- `404 Not Found`: `{ "error": "Хакатон не найден." }` / `{ "error": "Команда не найдена." }` / `{ "error": "Вы не состоите в команде." }`
- `400 Bad Request`: `{ "error": "Хакатон уже завершён." }` / `{ "error": "Капитан не может покинуть команду. Распустите команду." }` / `{ "error": "Проверьте поля формы.", "fieldErrors": ... }`
- `409 Conflict`: `{ "error": "Вы уже состоите в команде." }` / `{ "error": "Команда с таким названием уже существует." }`
