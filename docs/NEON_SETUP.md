# Подключение базы данных Neon

## Шаг 1: Создайте проект на Neon
1. Зарегистрируйтесь на [neon.tech](https://neon.tech).
2. Нажмите "Create Project".
3. Выберите имя проекта, например "hackathon-platform".
4. Выберите регион, ближайший к вам.
5. Нажмите "Create Project".

## Шаг 2: Получите DATABASE_URL
1. После создания проекта откроется панель управления.
2. Найдите раздел "Connection Details" или "Dashboard".
3. Скопируйте строку подключения (она начинается с `postgresql://`).

## Шаг 3: Настройте переменные окружения
1. Скопируйте файл `.env.example` в `.env`:
   ```bash
   cp .env.example .env
   ```
2. Откройте `.env` и вставьте вашу строку подключения в `DATABASE_URL`:
   ```env
   DATABASE_URL=postgresql://user:password@ep-xxx.neon.tech/dbname?sslmode=require
   ```
   **Важно:** никогда не коммитьте файл `.env` в Git и никому не передавайте строку подключения.

## Шаг 4: Примените схему к базе данных
Для применения SQL-миграций выполните:
```bash
npm run db:migrate
```

Если миграция падает при использовании pooled-подключения (`-pooler` в хосте), попробуйте прямое (не pooled) подключение из панели Neon.

Для быстрой синхронизации схемы без миграций (для разработки) можно использовать:
```bash
npm run db:push
```

Чтобы сгенерировать новую миграцию после изменения схемы:
```bash
npm run db:generate
```

Для просмотра таблиц и данных в браузере можно использовать Drizzle Studio:
```bash
npm run db:studio
```

## Шаг 5: Заполните базу тестовыми данными (seed)
После применения миграции загрузите начальный набор хакатонов:
```bash
npm run db:seed
```
Скрипт идемпотентный: повторный запуск пропустит уже существующие записи по полю `slug` (человекопонятный идентификатор для URL; внутренним первичным ключом при этом остаётся `uuid` в колонке `id`).

## Шаг 6: Проверка подключения
Проверьте подключение и количество записей в таблице `hackathons`:
```bash
npm run db:ping
```
