# О продукте

## Цель продукта

Создать простую и понятную веб-платформу для организации, поиска и проведения хакатонов, в которой человек без технической подготовки сможет разобраться с первого взгляда.

## Основные аудитории

- **Участники** — ищут хакатоны, собираются в команды и сдают проекты.
- **Организаторы** — создают и проводят хакатоны.
- **Менторы** — помогают командам во время проведения хакатона.
- **Жюри** — оценивают проекты участников.
- **Администраторы** — поддерживают работу платформы и следят за порядком.

## Главная идея

Пользователь должен быстро понять, что делать на экране, без обучения и сложных инструкций.

## Текущий этап

Базовый UI-каркас без бизнес-логики, авторизации и базы данных.

## Будущий стек

- **Фронтенд:** Next.js + TypeScript + Tailwind CSS + shadcn/ui
- **База данных:** Neon PostgreSQL (будет подключена позже)
- **ORM:** Drizzle или аналог (будет настроено позже)
