# Правила UX и интерфейса

При разработке экранов и компонентов необходимо соблюдать следующие принципы:

- Один экран — одна главная задача.
- Крупные кнопки и понятные подписи.
- Короткие фразы без технического жаргона.
- Каждая страница должна иметь понятный заголовок.
- Пользователь всегда должен понимать, где он и что делать дальше.
- Важные действия должны быть очевидными.
- Ошибки пишутся человеческим языком.
- Пустые состояния должны объяснять, что делать дальше.
- Интерфейс должен быть удобен на мобильных устройствах.
- Интерактивные элементы должны быть достаточно крупными.
- Цветовой контраст должен быть достаточным.
- Состояние загрузки, ошибки и успеха должны быть видимыми.
- Нельзя использовать тёмные паттерны или запутывающие формулировки.
